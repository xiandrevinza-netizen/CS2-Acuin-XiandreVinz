# CS2-Acuin-XiandreVinz
Student Grade Calculator

Description
This program calculates the average of two activity scores using input validation to handle errors

How to Run
1. Open the program file in VS Code, Replit, or OnlineGDB
2. Run the program
3. Enter the student's name and the scores for Activity 1 and Activity 2
4. Check the average score displayed on the screen

Input Needed
- Student name
- Activity 1 score
- Activity 2 score

Sample Outpu

Enter Activity 1 score: 85
Enter Activity 2 score: 90
